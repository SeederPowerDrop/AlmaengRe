# 1.1 이후 재개할 검증 · 2026-10-27

이 문서는 통과한 검사와 아직 수행하지 않은 검사를 구분하기 위한 인계 기록입니다. 미실행·무효 실행을 합격으로 변경하지 않습니다. 1.1 (105)은 검증된 1.0.49 (104)의 앱 기능 코드를 유지하며 버전만 변경했습니다.

## 현재 확보한 근거

- 1.1 배포 소스: Swift 핵심 회귀 44개 / 7개 suite 통과. 비교 작업 수명·메타데이터 정렬·분류·표시 품질 설정·세션·소개·10개 언어의 리소스 키와 서식 인수를 포함합니다.
- 1.1 Rust: 30개 통과, 1개 생략, 실패 0.
- 이전 1.0.49: 2026-10-22 회귀 144개 / 32개 suite와 실제 폴더 모델 통합 검사 1개 통과. 이미지 729개·영상 및 오디오 88개, 숨겨진 화면의 진행 콜백 0개, 원래 작업 복귀 검사. 이 수치를 1.1에서 전체 재실행한 결과로 표시하지 않습니다.
- 1.0.42의 전체 회귀·장시간 관측은 [기존 보고서](1.0.42-performance-qa.ko.md)에 별도로 보존합니다.

## 실제 폴더 모델 검사 재현

사용할 사진 폴더의 절대 경로를 직접 지정하고, 출력은 원본 폴더 밖의 새 시험 폴더로 정합니다. 테스트는 격리된 설정·분류 저장소를 사용합니다. 개인 사진·파일명·좌표·설정 사본은 GitHub에 올리지 않습니다.

```bash
./scripts/build-rust-engine.sh native
ALMAENG_QA_SOURCE='/absolute/path/to/photo-folder'
ALMAENG_QA_OUTPUT="$(mktemp -d /tmp/almaeng-comparison-qa.XXXXXX)"
IMAGEVIEWER_COMPARISON_WORKSPACE_QA=1 \
IMAGEVIEWER_RAW_DIRECTORY="$ALMAENG_QA_SOURCE" \
IMAGEVIEWER_COMPARISON_WORKSPACE_OUTPUT="$ALMAENG_QA_OUTPUT" \
swift test --disable-sandbox --no-parallel --filter RealRAWComparisonWorkspaceTests
```

화면 실측은 다른 앱의 자동 UI 검사가 끝난 뒤 진행합니다. 다른 채팅·앱을 임의로 중단하지 않으며 원래 작업 상태를 정상 저장합니다. 과거 설정 사본을 현재 설정으로 덮어쓰지 않습니다. 전체 소스를 다시 빌드해야 하는 새 환경에서는 테스트의 시간 제한과 준비 완료 여부도 확인합니다.
