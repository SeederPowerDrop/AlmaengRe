# 1.1 (빌드 105) 사전 릴리스 · 2026-10-27

비교 화면을 열어도 이전 지도·몽땅보기의 검색과 GPS 읽기가 계속되던 작업 수명을 정리했습니다. 비교 화면 진입 시 이전 검색·목록 읽기·대기 메타데이터 작업을 취소하고 진행 알림을 멈춥니다. 비교 중 바뀐 분류·검색·영상 조건은 원래 화면으로 돌아왔을 때 반영하며, 이전 사진·다중 선택·확대·이동·보기 모드를 보존합니다. 이미 실행 중인 동기 네이티브 디코딩은 끝날 때까지 처리 슬롯을 유지합니다.

비교의 형식 선택지는 원본 목록이 바뀔 때만 다시 계산합니다. 1.0.43 (빌드 98)에서 채택한 몽땅보기 크기 전용 상태도 포함합니다. 크기 슬라이더 값이 전체 AppStore의 화면 갱신으로 전파되지 않도록 범위를 줄이고 기존 설정 키·크기 정규화·저장 동작을 유지합니다.

## 게시 기준

공개 main의 1.0.42 (97) 위에, 실제 설치·검증한 1.0.49 (104)의 보존 소스 713개를 해시 검증해 반영한 뒤 앱 버전을 1.1 (105)로 갱신했습니다. 앱 기능 코드는 1.0.49와 같습니다. 로컬 작업 폴더의 1.0.48 (103)은 아직 채택하지 않은 별도 실험이며 해당 실험의 OverviewThumbnailCell 변경은 포함하지 않았습니다. 실험 소스와 과거 검증 자료는 로컬에 보존합니다.

사용자 요청에 따라 v1.1 사전 릴리스와 Apple Silicon·Intel 공용 ZIP을 배포합니다. 핵심 검증을 통과한 공개 시험판이며 전체 안정성 검증을 마친 안정판으로 판정하지 않았습니다. DMG는 제작하지 않습니다. 사용자 설명서·스크린샷·PDF와 검토 지문도 갱신하지 않았습니다.

## 검증 범위

2026-10-22에 1.0.49의 회귀 144개 / 32개 suite가 통과했습니다. 실제 폴더의 이미지 729개(그중 RAW 728개)와 영상·오디오 88개를 대상으로 별도 모델 통합 검사도 통과했습니다. 지도 헤더 읽기 중 비교로 전환한 뒤 숨겨진 화면의 진행 콜백은 0개였고, 복귀 후 헤더 처리가 완료됐습니다. 목록·선택·검색·확대·이동·페이지당 장수·보기 모드 복원을 검사했습니다. 원본 파일의 크기·수정 시각 등 메타데이터가 유지됐으며 전체 원본 바이트 해시 검사는 아닙니다.

기존 검증 기준인 Apple Silicon 앱은 1.0.49 (104), 당시 실행 파일 SHA-256은 `8fb327497258cb03f2f2960fbf27caf4bb6344daed7ebfdc7837ff8aa815c626`입니다. 설치 시 정상 종료로 최신 상태를 저장하고 설정 보존·서명·실행을 확인했습니다. 과거 설정 파일을 가져오지 않았습니다. Intel 실행 검사는 수행하지 않았습니다.

이 검사는 작업 취소와 상태 복원의 근거입니다. 전체 동작의 응답 시간 개선률·FPS·무지연·메모리 누수 부재를 입증하지 않습니다. 크기 변경과 필터 전환의 지연은 추가 검증 과제입니다. 1.0.42의 전체 회귀·장시간 관측 수치를 최신 1.0.49의 전체 재검사 결과로 간주하지 않습니다.

1.1 소스의 핵심 Swift 회귀 44개 / 7개 suite와 10개 언어 리소스 검사, Rust 30개(1개 생략)가 통과했습니다. Apple Silicon·Intel 공용 앱을 새로 빌드했습니다. 전체 회귀·최신 설치본의 대량 사진 성능·Intel 실제 실행 등 미완료 범위와 재개 절차는 [남은 검증 인계 기록](validation/1.1-remaining-validation.ko.md)에 보존합니다.

1.1 공용 ZIP을 실제 압축 해제해 코드 서명·버전·arm64/x86_64·10개 언어 리소스를 확인했습니다. `/Applications/알맹Re.app`에 설치한 최신 실행 파일과 ZIP의 실행 파일 해시가 일치하고 일반 앱 프로세스 실행을 확인했습니다. 설치 전후 설정 파일은 동일했으며 기존 실행 앱을 강제 종료하지 않았습니다. [1.1 배포 검증 결과](validation/1.1-release.json)에 해시와 검사 범위를 남겼습니다.
