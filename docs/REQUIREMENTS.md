## 0.2 추가 요청

| 요구사항 | 상태 |
|---|---|
| 썸네일 패널 상·하·좌·우 배치 및 숨김 | 구현, 설정 유지 |
| 확대 이미지의 대체 이동 방식 | 왼쪽/Space+왼쪽/오른쪽/가운데/두 손가락 중 선택 구현 |
| i 정보 아이콘과 상세 메타데이터 | 파일·픽셀·색상·TIFF·EXIF·GPS 표시 및 파일명·수정일·DPI·설명·카메라·GPS 편집 구현 |
| Apple 지도 / Google 지도 연동 | GPS가 있을 때 표준 URL 버튼 표시 |
| e 편집 아이콘 | 정보 패널과 분리 구현 |
| 빠른 로딩과 작은 앱 | 시스템 Quick Look 캐시 및 동적 프레임워크 재사용 |

“구현”은 현재 소스에서 실행 가능한 1차 기능을 뜻하며, 공개 배포 품질 완료를 뜻하지 않습니다. 배포 전 접근성, 다양한 Mac/모니터, 손상 파일 퍼징, 서명·공증 검증이 필요합니다.
