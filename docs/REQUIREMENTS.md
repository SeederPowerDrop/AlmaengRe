# 요구사항 진행표

| # | 요구사항 | 0.1 상태 | 다음 보강 |
|---:|---|---|---|
| 1 | 폭넓은 이미지 포맷 | 주요 현대/RAW/전문 포맷 + QOI/PCX 지원 | BPG, `.clip`, 희귀 코덱 플러그인 |
| 2 | 폴더/전체 썸네일/크기 조절 | 구현 | 재귀 폴더와 검색/정렬 UI |
| 3 | 1~10장 동시 보기 | 구현 | 사용자 지정 행·열 고정 |
| 4 | 트랙패드/키보드/설정 단축키 | 구현 | 관성 팬과 제스처 감도 설정 |
| 5 | HDR/SDR 고화질 | 16-bit float EDR 경로 구현 | 실제 HDR 모니터 회귀 테스트, gain-map 표기 |
| 6 | 한 장 집중 보기 | 구현 | 자동 숨김 세부 설정, 미니맵 |
| 7 | 가제 “이미지뷰어” | 적용 | 정식 이름·아이콘·번들 ID |
| 8 | HEIC → JPEG/PNG 등 변환 | 구현 | 다중 선택 일괄 변환 |
| 9 | 밝기/채도/하이라이트/반전/회전 | 구현 | 히스토그램, 화이트밸런스, 실행 취소 스택 |
| 10 | 대용량/RAW 안정성과 속도 | 축소 디코딩·캐시·비동기 파이프라인 구현 | 초대형 타일 피라미드, 벤치마크 묶음 |

“구현”은 현재 소스에서 실행 가능한 1차 기능을 뜻하며, 공개 배포 품질 완료를 뜻하지 않습니다. 배포 전 접근성, 다양한 Mac/모니터, 손상 파일 퍼징, 서명·공증 검증이 필요합니다.
