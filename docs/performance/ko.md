# 알맹Re 성능 시험 기록

**한국어** · [English](README.md) · [简体中文](zh-Hans.md) · [Русский](ru.md) · [Français](fr.md)

알맹Re 1.2(빌드 110)에 반영한 개선과 후속 사이드바 실험을 정리했습니다. 11월 시험은 Apple M3·통합 메모리 24GiB, macOS 15.7.5에서 진행했습니다. M2·16GiB 실기 시험은 남아 있습니다.

| --- | --- |

## 측정 기준과 남은 검증

직접 비교마다 파일 목록, 사전 준비 썸네일, 창의 가시 영역과 입력을 맞췄습니다. 가능한 경우 실행 순서를 뒤집고 시험 설정과 캐시를 분리했습니다. 자원 감시에서는 시스템 메모리 압력, 앱의 물리 메모리 표본과 스왑을 관측했습니다. 완료한 110 혼합 비교에서 압력은 정상이고 스왑 증가량은 0이었습니다. 캐시 예산은 캐시 데이터에 적용되며 앱 메모리에는 디코딩한 이미지와 코덱·렌더링 작업 공간도 포함됩니다.

프레임 발행, 타이머 공백, 독립 큐의 영상 출력은 각각 다른 관측값입니다. 화면에 실제로 나타나기까지의 지연과 합성기에서 빠진 프레임은 별도 시험이 필요합니다. M2·16GiB에서의 장시간 혼합 사용, 다른 앱의 응답성, 깊은 위치에서 크기를 바꿀 때 선택 사진이 화면에 남는지도 확인할 과제입니다.

## 과거 개선 작업과 시험 기록

9월 로딩 설계부터 10월 선로딩·캐시 왕복·혼합 사용 검증, 11월 RAW 복귀·크기 조절 개선까지 [성능 개선 연혁](history.ko.md)에 모았습니다. 채택한 변경, 당시 실패·미완료 검사, 공개 버전에 반영하지 않은 실험을 구분합니다.
