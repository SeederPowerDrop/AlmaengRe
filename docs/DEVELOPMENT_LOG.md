- 원본에 없는 세부 정보가 복원되는 것은 아니라는 설명 추가. 이번 버전은 명칭과 배치 변경이며 렌더 알고리즘 자체는 변경하지 않음

### 선명도 보강 검토 — 아직 미구현

- 현재 `ExtendedRangeBackingView`의 확대는 CALayer 선형 보간, 축소는 삼선형 필터. 계단 경계 완화와 선명도 보강을 구분
- 후속 후보는 macOS 내장 Lanczos 보간 + 약한 휘도 선명도 보정. [Apple Core Image 필터 문서](https://developer.apple.com/library/archive/documentation/GraphicsImaging/Reference/CoreImageFilterReference/index.html)의 `CILanczosScaleTransform`과 `CISharpenLuminance`를 확인
- 별도 대형 모델 없이 구현할 수 있는 경로이지만, 실제 확대 품질·테두리 번짐·노이즈 증폭은 표본 이미지로 비교 후 판단해야 함. 원본에 없는 세부 정보의 정확한 복원을 보장하지 않음
- 적용한다면 보기 전용 on/off·강도, 제스처 중 빠른 표시와 정지 후 보강, 출력 픽셀/메모리 예산, 오래된 요청 취소, HDR 부동소수점·프로파일 보존을 함께 설계. 원본·내보내기와 분리

## 2026-09-03 — 0.1 기반 구현

### 결정

- 반디뷰의 어두운 이미지 캔버스와 하단 플로팅 조작부를 참고하되 macOS 통합 툴바, 사이드바, 설정 창으로 재구성했다.
- 성능 엔진은 Rust부터 도입하지 않고 Image I/O + Core Image로 시작했다. 현재 macOS가 AVIF, JPEG XL, HEIC, WebP, EXR, DDS와 주요 RAW를 네이티브로 제공하기 때문이다.
- 시스템 미지원 범위를 검증하기 위해 QOI와 PCX 디코더를 앱 내부에 분리했다.
- 원본 파일을 수정하지 않는 것을 기본 안전 규칙으로 정했다.
