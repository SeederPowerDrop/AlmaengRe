# 개발일지

## 2026-09-03 — 0.1 기반 구현

### 결정

- 반디뷰의 어두운 이미지 캔버스와 하단 플로팅 조작부를 참고하되 macOS 통합 툴바, 사이드바, 설정 창으로 재구성했다.
- 성능 엔진은 Rust부터 도입하지 않고 Image I/O + Core Image로 시작했다. 현재 macOS가 AVIF, JPEG XL, HEIC, WebP, EXR, DDS와 주요 RAW를 네이티브로 제공하기 때문이다.
- 시스템 미지원 범위를 검증하기 위해 QOI와 PCX 디코더를 앱 내부에 분리했다.
- 원본 파일을 수정하지 않는 것을 기본 안전 규칙으로 정했다.

### 구현

- 빈 Swift Package 기반 macOS 앱 생성
- 폴더/파일/드롭 열기, 자연 정렬, 지연 로딩 썸네일
- 전체 보기 및 1~10장 자동 그리드
- 핀치 확대, 드래그 팬, 스와이프 및 키보드 탐색
- 사용자 지정 단축키 설정
- 애니메이션 이미지 재생
- GPU Core Image 보정과 다중 포맷 내보내기
- HDR/SDR 출력 전환과 제한형 메모리 캐시
- 앱 번들 빌드 스크립트와 GitHub용 기본 문서
- Apple Silicon/Intel Universal 2 앱 패키징

### 확인

- Swift 6.2 / Xcode 26.3 환경에서 debug/release 빌드 성공
- 레이아웃, 회전, QOI, PCX, PNG 내보내기 자동 테스트 6개 통과
- 실제 macOS 창에서 폴더 스캔, 썸네일, 단일/5장 이미지 렌더링 확인

### 다음 우선순위

1. 실제 대용량 RAW·EXR·파노라마 자료로 타일 렌더러 벤치마크
2. 여러 파일 일괄 변환 및 진행률/취소
3. ZIP/7z/RAR 이미지 묶음 읽기
4. EXIF 상세 보기, 북마크, 슬라이드 쇼
5. VoiceOver와 키보드 포커스 접근성 점검
