# 0.11.1 썸네일과 집중 보기 수정

일부 JPEG에서 macOS Quick Look이 완전히 투명한 썸네일을 성공으로 반환해,
하단에 검은 빈칸이 남던 문제를 수정했습니다. 픽셀을 확인하고 빈 결과는
원본에서 방향과 크기를 적용해 다시 만듭니다. 불투명한 검정 사진과 실제
투명 PNG는 정상 이미지로 유지하며 원본은 수정하지 않습니다.

일반 뷰어에서 사진 더블클릭 또는 Space를 짧게 눌렀다 떼면 집중 보기를
켜고 끕니다. Esc로도 돌아갈 수 있습니다. 검색창과 버튼 입력, 사용자 지정
Space 단축키 및 수정키 조합은 우선합니다. Space와 함께 드래그·스크롤하거나
다른 키를 누른 경우에는 키를 놓아도 보기 모드를 바꾸지 않습니다.

## 검증

- Swift 회귀 테스트 221개 / 33개 묶음 통과.
- 실제 문제가 발생한 JPEG의 256·512px 썸네일을 원본에서 정상 복구 확인.
- 불투명 검정·투명 PNG·방향·16비트 변환·실패·취소 회귀 검증.
- Space 반복 입력·검색 입력·사용자 단축키·창 전환·확대 위치 보존 검증.
- 실제 UI에서 더블클릭·Space 진입/복귀, Esc 복귀, 검색 공백 입력과 사진 클릭 후 입력 위치 전환 확인.
- 밝고 어두운 가로·세로 이미지의 1장·10장 보기 확인.
- arm64·x86_64 Universal 앱 빌드, 로컬 서명 및 ZIP 무결성 검사 통과.

검증 환경은 Apple Silicon / macOS 15.7.5입니다. Intel 실기기 실행과
Developer ID 서명·공증은 포함하지 않습니다.

0.11.0의 Rust 엔진과 라이브러리 기능은 유지합니다. 이번 패치는 같은
`codex/rust-engine-library-upgrade` 브랜치에서 제공하며 `main`은 변경하지 않습니다.
