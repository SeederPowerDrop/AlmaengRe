# 0.11.0 개발 버전

기존 0.10.2는 `main`과 `v0.10.2`에 보관합니다. 이번 변경은
`codex/rust-engine-library-upgrade`에서 검토하며 아직 main에 병합하지 않습니다.

## 사용자가 달라지는 점

- **같은 파일명 비교:** 확장자를 제외한 이름으로 A/B를 짝짓습니다. 없는 쪽은
  ‘대응 이미지 없음’으로 표시합니다. 목록 순서 방식과 적은 쪽 유지·반복도 남아 있습니다.
- **폴더 즐겨찾기·마지막 보기:** 트리 상단에 폴더를 고정하고, 재실행 시 일반 사진,
  검색·정렬·형식 필터, A/B 사진·배율·잠금·위치를 복원합니다.
- **AI 확대:** 앱에 포함한 QuickSRNet Small 2× 모델을 Core ML로 로컬 실행합니다.
  원본/결과 확인, 실제 픽셀 보기, 진행률·취소, PNG 사본 저장을 제공합니다.
- **검색·정렬:** 파일명 검색, 이름·수정일·생성일·용량, GPS 4방향 정렬을 제공합니다.
  GPS가 없는 사진은 뒤에 둡니다. 비교 행에도 선택한 정렬을 적용합니다.
- **형식 선별:** JPEG·PNG·HEIC·RAW·GIF·WebP·TIFF·기타를 복수 선택합니다.
- **ZIP:** 별도 압축 해제 조작 없이 내부 이미지 목록을 읽기 전용으로 엽니다.
  검색·정렬·형식 필터·보기 복원이 같은 방식으로 동작합니다.

## 엔진

Rust로 폴더 목록, 매칭, 검색·필터·정렬, ZIP, QOI/PCX 파서, 픽셀·캐시·동시성 예산과
적응 정책을 옮겼습니다. UI와 권한, Apple 이미지·색 관리·HDR·AI 프레임워크,
네이티브 이미지의 수명과 actor 스케줄링은 Swift에 남습니다.
FFI 버퍼는 명시적으로 해제하며 비정상 입력과 크기 상한을 검사합니다.
Rust 전환 자체가 전체 앱의 메모리 누수 부재나 속도 향상을 보장하지는 않습니다.

## 검증

Apple Silicon Mac에서 다음을 확인했습니다.

- Swift 회귀 테스트 **211개 / 31개 묶음 통과**.
- Rust 단위 테스트 **17개 통과**.
- arm64·x86_64 Universal 앱 생성, 로컬 서명 및 ZIP 무결성 검사.
- 통합 열기로 일반 폴더, A/B 폴더, ZIP 불러오기.
- 같은 이름의 JPEG/PNG 짝짓기, 중간 누락 표시, 썸네일·잠금·상하 배치·확대.
- GPS 북→남 정렬과 위치 없는 사진의 후순위 표시.
- 즐겨찾기, 검색, PNG 필터, 결과 없음 및 초기화.
- 재실행 후 ZIP 마지막 사진, A/B 행·잠금·배율·배치 복원.
- 밝고 어두운 가로·세로 이미지의 1장·10장 보기.
- 실제 AI 추론과 640×400 → 1280×800 PNG 사본 저장.

추가 AI 검증에서 변환 전 모델과 Core ML CPU 결과의 최대 오차는 0.0이었습니다.
1280×800 합성 입력의 2배 확대와 PNG 저장은 이 Mac에서 0.76초,
최대 RSS 약 68 MiB였습니다. 특정 합성 입력의 참고치이며 일반 성능 보장이 아닙니다.

## 현재 범위

- 검색은 파일명을 대상으로 합니다. 사물·내용·OCR 검색은 포함하지 않습니다.
- AI 출력은 2배, 8-bit SDR sRGB, 최대 6,400만 픽셀입니다. 투명도를 유지하고
  애니메이션은 첫 프레임만 처리합니다. HDR AI 출력·일괄 AI 처리는 포함하지 않습니다.
- ZIP은 Stored/Deflate를 지원합니다. 암호화와 다른 압축 방식은 오류로 알립니다.
  압축 입력 2 GiB, 디렉터리 16 MiB, 1만 항목, 항목당 256 MiB·전체 1 GiB 해제 한도가 있습니다.
- Intel 아키텍처 빌드와 링크는 확인했지만 Intel 실기기 실행·AI 추론은 확인하지 않았습니다.
- 로컬 ad-hoc 서명입니다. Apple Developer ID 서명·공증은 포함하지 않습니다.

모델·Rust 의존성의 라이선스 원문을 소스와 앱에 포함합니다.
