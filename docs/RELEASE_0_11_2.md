# 0.11.2 집중 보기 조작창

- 집중 보기 하단 조작창의 ×는 조작창만 숨깁니다. 사진 넘김이나 마우스 재진입으로 다시 나타나지 않습니다.
- 집중 보기 종료 ×는 상단 파일명 왼쪽으로 옮겼습니다. Esc·Space·더블클릭 복귀도 유지합니다.
- 숨긴 조작창은 상단 파일명 오른쪽의 조작창 표시 버튼으로 다시 열 수 있습니다.
- 여러 장 보기에는 첫 번째 타일에만 종료·표시 버튼이 있습니다. 파일명을 숨긴 설정에서도 버튼은 유지합니다.
- 집중 보기를 종료했다가 다시 진입하면 조작창을 다시 표시합니다. 조작창 숨김 자체는 사진이나 전자 앨범 재생 상태를 바꾸지 않습니다.

## 검증

- 변경 전후 Swift 테스트 221개 / 33개 묶음 통과.
- 8개 언어 문자열 문법, 중복 및 키 일치 검사 통과.
- 실제 UI에서 하단 × 숨김 후 사진 넘김·마우스 재진입에도 숨김 유지 확인.
- 상단 버튼으로 조작창 복원, 파일명 왼쪽 ×로 집중 보기 종료, 재진입 시 조작창 초기화 확인.
- 밝고 어두운 가로·세로 이미지의 1장·10장 보기와 파일명 숨김 설정에서 검증.
- arm64·x86_64 Universal 앱 빌드, 로컬 서명 및 ZIP 무결성 검사 통과.

실행 검증은 Apple Silicon / macOS 15.7.5에서 수행했습니다. Intel 실기기 실행과
Developer ID 서명·공증은 포함하지 않습니다.

0.11.1의 썸네일 복구와 0.11 엔진 기능은 유지합니다. 변경은
`codex/rust-engine-library-upgrade` 브랜치에서 제공하며 `main`은 변경하지 않습니다.
