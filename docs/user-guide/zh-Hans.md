## 1. 打开图像、文件夹和 ZIP 压缩包

通过“打开…”载入照片、视频、文件夹和ZIP。默认同时显示照片和受支持的视频；ZIP仅包含图像。

![主页汇集应用图标、打开按钮和最近看过的照片。](figures/home.png)

**界面 01.** 主页汇集应用图标、打开按钮和最近看过的照片。

1. **打开或继续** — 用“打开…”载入新列表，或用“继续上次的工作”返回已保存的工作。
2. **最近的 7 张照片** — 最多显示 7 张在查看器或图像对比中看过的照片，最近查看的排在前面；点击可重新打开。包含普通图像、GIF 和 ZIP 内的照片，不含视频。
3. **整理最近列表** — 单张照片的“从列表移除”或“清空列表”只删除历史记录，保留原始文件。之后再次查看照片时，照片可能重新出现在列表中。

### 操作步骤

1. 在 macOS 14 或更新版本上启动 알맹Re，会显示主页。选择“打开…”（⌘O）或点击最近的照片。工具栏和“文件”菜单中也可使用“打开…”。
2. 选择文件夹即可浏览其中的文件。打开一张照片后可继续浏览同一文件夹；选择多个文件时仅打开所选文件。“显示视频”默认开启，并记住你的选择。直接打开视频会自动开启此选项。
3. 选择 ZIP 可查看其中支持的图像，包括压缩包子目录中的图像。也可以从 Finder 打开文件，或将图像和文件夹拖入应用。

### 文件夹与收藏

“文件夹树”按需展开文件夹。点击文件夹名称即可打开，用向上箭头进入上一级；在 Finder 中更改文件后可刷新。将文件夹固定在树状列表上方可方便访问。打开普通文件夹不会自动包含其所有子文件夹。

### ZIP 为只读

压缩包打开期间，图像会解压到临时文件夹。重命名或编辑原始元数据前，请先导出副本。应用不会改写 ZIP。支持 Stored/Deflate 压缩方式，不支持加密压缩包或其他压缩方式。上限包括：压缩包 2 GiB、10,000 个条目、每个条目解压后 256 MiB、全部解压数据 1 GiB。 不支持ZIP中的视频。

### 主页与上次的工作

正常启动时显示主页。“继续上次的工作”会尽可能恢复上次的列表、选择、查看模式和搜索条件。工具栏或菜单中的“主页”保留当前工作并返回主页。从 Finder 等应用打开文件会直接显示该文件。若连接或权限改变，请用“打开…”重新选择。重启后不恢复编辑调整和未保存的 AI 结果。

### 实用提示

- 同时选择文件夹和单独图像时，会汇集图像并去除重复项。“图像对比”仅处理图像；其中，“打开…”会更改当前选中且未锁定的 A 或 B 窗格。 “帮助 → 基本用法”在应用内打开简要说明。“帮助 → 详细使用手册 (GitHub)”在默认浏览器中打开 GitHub 上相应语言的完整指南。

## 2. 浏览图像与专注查看

查看器每屏可显示一至十张图像。可以放大查看细节，也可以隐藏周围控件，专注欣赏照片。 多图视图中的视频先显示静态预览，将指针移到视频上会静音播放。

![查看器同时显示多张照片和视频。将指针移到视频上可静音预览。](figures/viewer.png)

**界面 02.** 查看器同时显示多张照片和视频。将指针移到视频上可静音预览。

1. **查看模式** — 切换查看器、一览无余、地图视图和图像对比。
2. **搜索、筛选与视频显示** — 调整当前列表的搜索、格式、分类、排序和“显示视频”。
3. **查看控件** — 浏览项目并调整显示数量，也可设置照片缩放和平移方式。

### 操作步骤

1. 在顶部选择“查看器”，用 ← 和 → 移动。通过张数控件或 \[ 和 \] 设置每屏图像数；网格会随窗口形状自动调整。
2. 在触控板上捏合，或按 = 和 − 缩放。按 0 使用“适合窗口”，按 1 使用“实际大小”。可从底部控件或“设置 → 通用”选择平移方式。
3. 按 F、双击照片或短按 Space 切换专注模式，按 Esc 返回。“全屏”是另一项功能，快捷键为 ⌃⌘F。

### 一次浏览多张图像

查看器中的←/→始终按设置的每屏项目数移动，分类 ON 或 OFF 都一样。显示多个项目时，↑/↓选择当前屏幕内的上一行或下一行，到第一行或最后一行即停止。最后一行不满时选择最接近的现有卡片。⌥←/⌥→始终按整屏移动，分类期间也一样。

### 平移操作

可以选择左键拖动、Space＋左键拖动、右键拖动、中键拖动或触控板双指移动。⌃⌥1–5 用于选择平移方式，按下这些键不会直接移动照片。横向轻扫在未用于平移图像时切换前后图像。 拖动过程中，图像边缘也只允许留出少量余量，避免照片被推入大片空白。小于显示窗格的轴始终居中；改变窗口大小或缩放后会重新调整移动边界。多图查看和缩放质量对比也遵循相同规则。

### 专注模式的控件

底部的 × 只隐藏浮动控制条，可用文件名旁的按钮重新显示。顶部的 × 退出专注模式。即使隐藏文件名，这些按钮仍然可用。正在输入文字或已为 Space 设置自定义快捷键时，短按 Space 不会切换专注模式。

### 实用提示

- 缩略图可显示在左、右、上、下方，也可隐藏。Esc 会先退出当前临时查看模式，再从普通查看器返回“一览无余”。

## 3. 在“一览无余”中查找和选择图像

“一览无余”将当前集合铺成缩略图网格，便于快速查看文件夹、选出照片并准备批量操作。 视频显示为静态预览，不会播放。

![“一览无余”结合了缩略图网格、搜索、选择和大小调节。](figures/overview.png)

**界面 03.** “一览无余”结合了缩略图网格、搜索、选择和大小调节。

1. **缩略图网格** — 点击、范围选择或拖动来选择卡片。视频显示静止预览，双击可全屏打开。
2. **搜索、筛选与视频显示** — 调整当前列表的搜索、排序、格式、分类和视频显示。
3. **大小与选择** — 调整预览大小，并通过所选图像操作进行批量处理。

### 操作步骤

1. 在“一览无余”（G）中调整缩略图大小。双击照片可在查看器中打开，双击视频则全屏打开。
2. 在“搜索文件名”中输入内容。搜索不区分大小写，以空格分隔的每个词都必须出现在文件名中。可选择一种或多种格式，或用“所有格式”清除格式筛选。
3. 点击选择，⌘点击添加或移除，⇧点击选择范围。从卡片或空白处拖出矩形，选择相交的卡片。分类 ON 或 OFF 时，←/→均每次移动一张卡片，↑/↓每次移动一行。到第一行或最后一行即停止；最后一行不满时选择最接近的现有卡片。按地图区域筛选的列表也一样。分类 OFF 时优先使用自定义快捷键。

### 选择快捷操作

开始拖出选框时按住 Shift，可添加到现有选择；按住 ⌘ 可切换选框内图像的选中状态。Esc 恢复拖动前的选择。⌘A 选择当前可见列表中的全部图像。

### 排序当前列表

排序分为“名称与文件”“尺寸与拍摄时间”“相机与色彩”和“位置”。除了原有条件，还可按宽度、高度、拍摄时间、文件类型、快门速度、制造商、型号、光圈和色彩空间排序。名称按自然数字顺序比较，快门速度按曝光时长、光圈按f值比较。缺失值在升序和降序中都排在最后。文件类型基于扩展名，并将JPEG、TIFF的等价扩展名合并。不会更改原文件。

### 编号与预览大小

# 控件显示或隐藏缩略图编号。较大的编号会移到小照片外，避免遮挡图像。缩略图大小设置会保存，范围为 44.8–665.6 点，单个单元格还会受窗口宽度限制。

### 拍摄信息排序的范围

宽度与高度是应用文件方向后的原始像素尺寸，不包含查看器中的调整。拍摄时间使用EXIF或视频内嵌的日期，不以文件创建日期代替。排序时，没有时区的EXIF会将记录的时间按UTC处理。视频使用可读取的尺寸、日期、制造商、型号及色彩信息；快门速度和光圈视为未知。仅在选择相关排序时读取信息并重复使用，因此首次排序可能需要一些时间。

### 实用提示

- 搜索仅针对文件名，不搜索图像内容或OCR文字。无匹配结果时，控件仍在顶部；可用“重置搜索和筛选”恢复。文件不会被删除。关闭“未分类照片”且未选任何分类时，不按分类限制照片。

## 4. 对比两个图像集合

“图像对比”将独立的 A、B 集合左右或上下排列，适合比较不同版本或检查两个文件夹。

![“图像对比”中的两个图像集合。](figures/compare.png)

**界面 04.** “图像对比”中的两个图像集合。

1. **A、B 窗格** — 在窗格名称下查看已选分类键、条件和照片数。关闭“未分类照片”且未选择分类键时，会显示所有照片；A/B可包含同一照片。结果为空时检查分类及共用的搜索、格式和地图条件。清除只移除该窗格的分类筛选条件。
2. **对比方式** — 选择配对方式、导航对象、较短一侧循环和同步缩放。
3. **分类应用于** — ON 时，为分类键和下方按钮选择“仅 A”“仅 B”或“两侧”，与切换目标相互独立。− 表示仅部分照片已有该分类。

### 操作步骤

1. “按分类对比当前照片”将原始列表同时打开到A/B，保留搜索、格式和地图条件。只有A继承普通分类筛选，B从所有照片开始。其他文件夹可用“图像对比”（⌃⌥C）的“选择要对比的文件夹…”或各窗格的“打开…”打开。
2. 使用各窗格名称下的分类按钮，从现有12个分类中选择多个，例如A选1·F，B选3·Q·S。默认为“任一所选分类”（OR），也可选“全部所选分类”（AND）或“未分类照片”。
3. 在“图片切换”中按显示名称选择一侧或“两侧”。使用共用方向按钮或各窗格的缩略图移动。开启“同步缩放与移动”可检查对应的相对位置。 每个窗格的平移也仅允许少量边缘余量，小于窗格的轴保持居中，缩放或窗口大小改变后会重新调整边界。

### 导航与循环

筛选结果可按“列表顺序”浏览，或按“相同文件名”配对。忽略扩展名，如001.jpg与001.png配对；缺少对应照片的一侧保留为空。选择单侧导航会切换到“列表顺序”，选择同名则成对移动。“两侧”下的“循环较短的一侧”让短列表从头循环；关闭后停在最后一张。循环仅用于“列表顺序”。

### 分类目标与锁定

分类 ON 时，在底部“分类应用于”选择“仅 A”“仅 B”或“两侧”，作用于分类键和下方按钮。它独立于当前窗格和切换目标，默认“仅 A”，选择在本次应用运行期间保留。“两侧”中只有部分照片带标记时显示 −；按下会给两侧都添加，若两侧已有则都移除。同一照片只处理一次。所有目标照片必须已实际显示；一侧为空或加载中时，“两侧”不可用。锁定的照片仍可分类。 锁定固定照片、缩放、位置和分类条件。锁定 B 后切换 A，锁定 A 后切换 B；全部解锁后切换目标恢复“两侧”，全部锁定停止切换。锁定的缩略图仍可查看和滚动。

### 原图与保存的状态

对比显示未经调整的原图，不含视频。编辑、批量操作或设置壁纸前请退出；Esc返回之前的视图。布局、同步、导航、上次A/B输入、位置和各窗格分类条件会保存并恢复。打开其他输入也保留分类条件。“对比名称…”可设置最多80字的别名。留空或“使用自动名称”会使用文件夹/ZIP名称；“保存”应用，“取消”保留当前名。同一文件夹/ZIP或混合列表用A/B区分，同名的不同文件夹附加(A)/(B)。别名不改变文件夹名，重启及重新打开相同输入时保留，仅打开新输入的窗格会重置。将指针停在缩略名称上可看全名。

### 实用提示

- ⌥←/⌥→ 仅导航 A，⇧⌥←/⇧⌥→ 仅导航 B。“相同文件名”忽略扩展名、大小写和等价 Unicode 字符表示的差异。

## 5. 分类照片和视频

浏览照片和视频时，可添加多个个人标签。仅分类 ON 时能更改；分类是应用内标记，不是对原始文件执行操作。

![分类 ON：键盘和底部按钮用于当前项目，各卡片另有分类菜单。](figures/tags.png)

**界面 05.** 分类 ON：键盘和底部按钮用于当前项目，各卡片另有分类菜单。

1. **分类 ON/OFF** — ON 时可更改分类；OFF 恢复普通查看快捷键。
2. **按键和底部按钮** — 切换当前项目的分类，可添加多个标记。
3. **每张卡片的分类菜单** — 仅更改该照片或视频，不改变当前选择或多选状态。

### 操作步骤

1. 用分类 ON/OFF、“照片分类”菜单或 ⌘⇧M 切换。开启会结束搜索输入。分类键作用于当前项目；对比中则遵循底部“分类应用于”的“仅 A”“仅 B”或“两侧”。
2. ON 时，用固定物理位置的 1–4、QWER、ASDF 或底部按钮添加或移除分类。查看器或一览无余中，各卡片的分类菜单仅更改该照片或视频，不改变选择状态，也不批量更改多选项目。
3. 普通查看时，用 ⌘⇧M、Esc 或面板关闭按钮切换到 OFF。分类筛选可显示“任一所选分类”“全部所选分类”或“未分类照片”。“图像对比”中在各窗格名称下分别设置条件。

### 保持稳定的浏览节奏

分类后不会自动前进。ON 时列表保持稳定，查看器的←/→每次移动一整屏；OFF 时更新结果。对比也暂缓自动更新，但直接改变条件会立即生效。查看器中，目标照片或视频预览显示后才能分类。

### 按键的含义

默认名称为1–4：一颗星、两颗星、三颗星、四颗星；Q 上传、W 调整、E 删除、R 待定；A 风景、S 人物、D 物品、F 动物。它们都只是可编辑的标记，按键不会上传、调整、删除或移动文件。已保存的分类名称会保留。

### 保存在本机

照片所属分类、分类名称和颜色保存在应用的本地数据库中，重启后仍可使用。它们与 EXIF 元数据分开，不通过 XMP 或云端照片图库同步。

### 实用提示

- OFF 时，1 和 F 恢复实际大小和专注模式。全屏视频上方也有分类开关和菜单，分类键仅作用于该视频；此时 ←/→ 仍调整播放位置，Esc 优先退出全屏。

## 6. 设置分类名称、颜色与了解跟踪范围

为十二个分类键设置适合工作的名称。相同分配适用于所有文件夹，改名后照片已有的分类仍然保留。

![分类名称与颜色的共用编辑界面。](figures/tag-editor.png)

**界面 06.** 分类名称与颜色的共用编辑界面。

1. **按键名称** — 每个固定按键都有可编辑名称，所有文件夹共用。
2. **颜色** — 从十色调色板中选择一致的视觉提示。
3. **预览与保存** — 检查按键分配，然后保存，以便下次继续使用。

### 操作步骤

1. 打开“设置 → 照片分类”，或选择“照片分类 → 编辑分类名称与颜色…”。无需先打开照片。
2. 输入各键名称，并从十种颜色中选择。输入时，“按键对应的分类”预览会实时更新。
3. 点击“保存”将名称和颜色应用到各处。设置中的“撤销更改”恢复上次保存的分配；独立编辑窗口中的“取消”则不保存并关闭窗口。

### 一致的视觉标记

颜色会出现在分类面板、菜单、筛选和缩略图标记中。勾选标记和选中背景也会表示分类状态，因此不只依靠颜色辨认。更改名称或颜色不会清除照片已有的分类。

### 重命名与移动

在应用内重命名时，分类会随之更新。应用保存已分类照片的macOS书签和文件身份信息，尽可能跟踪Finder改名及同一磁盘卷内的移动。在启动、报告中重新检查或打开目标图像列表时进行核对，并非持续监视文件系统。ZIP内的图像通过压缩包与内部路径识别。 在Finder等应用中改名或移动后，请重新打开文件夹以刷新当前图像列表。仅重新检查报告不会刷新已经打开的列表。

### 跟踪限制与已保存报告

在“照片分类 → 分类文件报告…”中查看找不到文件、名称或位置变更、重新找到文件的记录。历史在重新启动后仍保留。磁盘未连接或权限不足也会使文件不可用，因此不会将其直接判断为已删除。副本和同路径的替换文件不继承分类。跨卷移动、失效书签或权限变化可能使跟踪失败。旧版仅按路径保存的分类，应先在原位置打开一次照片再移动。

### 实用提示

- 分类、名称、颜色和报告保存在此Mac的SQLite数据库 ~/Library/Application Support/org.openimageviewer.ImageViewer/PhotoMarks.sqlite 中，不写入原照片。应用不会搜索整个磁盘或分析照片内容来寻找丢失文件。请将原图和应用本地数据纳入备份。

## 7. 按位置查找照片

“地图视图”将含 GPS 元数据的照片放在地图上。最多可组合三个区域，一起浏览不同地点的照片。

![包含可选区域和匹配照片概览的地图视图。](figures/map.png)

**界面 07.** 包含可选区域和匹配照片概览的地图视图。

1. **区域工具** — 添加圆形、矩形、自由绘制边界或当前地图范围。
2. **区域手柄** — 移动和缩放当前区域，最多可组合三个区域。
3. **浏览结果** — 在查看器或一览无余中打开区域结果，或通过“区域照片操作”批量处理与共享。

1. 打开集合后选择“地图视图”。附近的照片会合并为带张数的堆叠缩略图。点击地点可预览其中图像，再用“查看照片”打开一张。
2. 选择“半径”或“矩形”，在当前地图中心添加区域。拖动编号手柄可移动，拖动小尺寸手柄可调整大小。半径也可按千米输入。
3. 选择“自由绘制区域”描出边界，或添加“当前地图区域”。最多添加三个区域，再用“在查看器中打开”或“在总览中打开”浏览匹配照片；后者打开“一览无余”。 使用“区域照片操作”可直接重命名、转换、缩小或共享此范围的结果。图钉菜单可处理一张照片或该位置的全部照片。

### 组合和编辑区域

位于任一所选区域的照片都会包含，区域重叠时同一照片只显示一次。选择“区域 1、2、3”进行编辑，用各自的 × 删除，或全部清除。Esc 可取消自由绘制，也可撤销正在进行的移动或调整大小。

### 保留所选集合

查看器和“一览无余”上方会显示蓝色“仅显示地图中选定的照片”状态栏，列出区域数和显示的照片数。专注模式或结果为空时也会保留。 在查看器或“一览无余”中打开选择结果后，地图范围条件仍然生效，文件名、格式和分类筛选也同样适用。“清除地图区域”返回不限制位置的筛选列表，包括没有 GPS 的图像。打开所选范围外的地图照片时，只清除位置限制。

### 加载与保存状态

从其他查看模式选择“返回地图”或“地图视图”，可恢复上次的地图位置和缩放。重新启动应用时，地图会适配已恢复的选择区域，而不会恢复精确位置。打开新文件夹会重置区域选择和地图位置。地图背景需要互联网连接。没有 GPS 的照片不显示，大型集合的位置读取可能需要一些时间。

### 实用提示

- 没有匹配照片时，请扩大或移动区域，并检查其他筛选。结果正在加载或为空时，打开选择结果的按钮不可用。

## 8. 检查图像信息和元数据

圆形 i 按钮仍是“图像信息”，用于查看当前照片的详情。应用自身的介绍位于“帮助 → 关于应用”。

### 操作步骤

1. 选择照片后点击圆形 i 按钮，或使用“导航 → 图像信息面板”。
2. 查看文件大小、图像尺寸、颜色信息和可读取的相机/EXIF 数据。存在 GPS 时，面板会显示 Apple 地图；Google 地图按钮会在外部打开同一坐标。
3. 需要更改支持的文件信息或嵌入字段时，打开“编辑图像信息”，修改数值，并在“保存”前核对。

### 保存元数据会更改文件

与视觉调整不同，元数据编辑会写回源文件。可编辑字段包括文件名、修改日期、说明、版权、DPI、相机信息，以及格式支持时的 GPS。编辑器先准备临时文件，再替换原路径的文件。不支持的嵌入字段会禁用，ZIP 内的图像为只读。

### 移除或修正数值

清空可编辑文字字段并保存，会移除该标签。关闭 GPS 会移除标准 EXIF/XMP 位置标签。坐标需要同时有纬度和经度。更改扩展名不会转换图像，应使用导出或批量转换格式、调整尺寸与压缩。

### 正确阅读直方图

RGB 和亮度直方图描述的是按透明度加权的 SDR 预览，并随编辑调整更新。黑色和白色百分比统计预览中所有 RGB 通道均为 0 或 255 的像素。它不是 RAW 传感器直方图，也不测量原始 HDR 的亮度范围。

### 实用提示

- 修改以后可能需要撤销的元数据前，请先保留副本。i 图标用于照片信息；“帮助 → 关于应用”打开应用介绍和许可信息。

## 9. 编辑图像并导出副本

“图像编辑”预览更改而不覆盖原图。视觉调整只在本次应用会话中保留，请在退出前导出结果。

![当前图像预览旁的编辑面板。](figures/editing.png)

**界面 08.** 当前图像预览旁的编辑面板。

1. **质感与胶片风格** — 展开“质感”进行调整，或选择胶片风格和强度。
2. **图像预览** — 检查当前结果；调整细节时使用“实际大小”。
3. **保存副本与添加水印** — 选择格式和质量后导出副本。“添加水印…”仅针对当前照片。

### 操作步骤

1. 选择照片后点击滑块形的“图像编辑”按钮。从“一览无余”打开时，会切换到该照片的查看器。
2. 在图像上拖出矩形进行裁剪。从内部拖动可移动，拖动角点可改变大小，也可输入比例和尺寸。确认后应用裁剪；取消裁剪窗口会保留之前的编辑。可按 90° 步进旋转，或使用“水平翻转”“垂直翻转”。
3. 调整光线、颜色和细节。在编辑面板中选择可用输出格式与质量，然后点击“导出…”或按 ⌘E 保存新文件。

### 调整选项

使用曝光、亮度、对比度、高光、阴影、黑点和白色调整色调；使用色相、色温、自然饱和度和饱和度调整颜色。色调曲线可用五个控制点调整 RGB 整体或单独通道。八色混色器可分别调整每种颜色的色相、饱和度和明度。还可使用纹理、清晰度、去朦胧和胶片风格。

### 重置与检查

“重置”移除当前照片的所有视觉调整。“移除裁剪”保留其他编辑。再次点击相同翻转按钮会撤销该次翻转。请在“实际大小”和导出结果中检查锐化与降噪效果。

### 退出前保存

只要应用仍打开，每张照片就会保留自己的调整；下次启动不会恢复。导出的默认名称以 -edited 结尾，并阻止覆盖源文件。可用格式取决于 macOS 提供的编码器。

### 实用提示

- “图像对比”显示原图，不包含这些调整。“AI 放大”也使用未包含查看器编辑的源图像。如果希望放大编辑后的效果，请先导出编辑副本。

## 10. 批量重命名、转换、缩小与共享图像

可对查看器、一览无余、分类筛选后的列表和地图中选取的照片进行批量操作。重命名会修改源文件名称；转换格式、调整尺寸与压缩则创建新文件。也可使用macOS原生共享功能。

![设置格式、按比例缩小及保存位置的批量转换窗口。](figures/batch.png)

**界面 09.** 设置格式、按比例缩小及保存位置的批量转换窗口。

1. **格式与大小** — 选择输出格式和等比例尺寸。有损格式可调质量，也可使用减小文件大小预设。
2. **水印与保存文件夹** — 打开水印设置，或选择保存副本的文件夹。
3. **保存预览** — 比较当前名称与输出名称后转换，原文件保持不变。

### 操作步骤

1. 在缩略图中点击、⌘点击、⇧点击或按⌘A选择照片；在一览无余中还可拖出选框。可以先按分类筛选。地图的“区域照片操作”处理所选范围；图钉菜单的“此照片操作”或“此位置的全部照片操作”处理对应照片。
2. 在“批量重命名…”中保留或替换名称、查找替换文字，或添加前缀、后缀与序号。选择“使用分类名称”后，明确选择“用于命名的分类”。仅处理所选文件中属于该分类的照片。应用前检查新旧名称预览。
3. 在“批量转换格式、调整尺寸与压缩…”中选择输出格式、质量、图像大小和目标文件夹，检查输出名称预览。“共享文件…”将所选原始文件交给macOS共享面板；“共享已完成的文件…”共享成功导出的文件。可用的共享方式取决于macOS提供的服务。

### 分类名称与编号

“使用分类名称”按当前列表顺序生成上传01、上传02等名称。目标不超过99个时使用两位数；达到100个时改用001、002等三位数，达到1000个时继续增加位数。照片有多个分类时，仅按明确选择的分类处理一次，其他所选文件保持不变。普通序号默认两位，可设置起始值、递增量、补零位数和分隔符。分类名称为空、名称无效或冲突时不能应用。不能直接重命名ZIP内的文件。

### 格式、尺寸与文件大小

修改扩展名仅支持大小写及.jpg/.jpeg等同格式别名。将HEIC转为JPEG，请用“批量转换格式、调整尺寸与压缩…”。“按长边”或“按百分比”在应用当前调整和裁剪后按比例缩小，不会放大小图。“减小文件大小预设”使用JPEG、长边1920像素和75%质量。最终文件大小因照片而异，也可能比原文件更大。

### 原图、完成结果与共享

转换会应用当前图像调整并创建副本，保留原文件。输出名称被占用时追加编号。动画和多页图像只保存第一帧。停止操作后已完成的文件仍会保留，结果显示已保存、失败和未处理数量。共享原文件不会包含尚未保存的调整；需要共享调整或缩小后的图像时，先完成转换，再共享已完成的文件。 选择中包含视频时，不能进行批量图像转换。如需保留视频或动画的动态片段，请使用“帧与片段编辑…”。

### 实用提示

- 重命名前请检查目标数量和预览。应用内重命名会保留分类关联；导出的副本视为独立照片，不会自动继承分类。在macOS共享面板中选择目标和发送操作。

## 11. 添加文字、EXIF与徽标水印

为一张或多张所选照片的副本组合添加文字、签名、拍摄信息和徽标图像。原文件及其分类保持不变。

![组合文字、EXIF和徽标，在预览中拖动水印，并选择是否扩展画布。](figures/watermark.png)

**界面 10.** 组合文字、EXIF和徽标，在预览中拖动水印，并选择是否扩展画布。

1. **文字、字体与EXIF** — 选择文字、字体和各照片的EXIF。增加项目时保持文字大小。
2. **徽标与位置** — 选择徽标，用滑块或数值调整大小、边距和不透明度。
3. **第一张照片预览** — 拖动水印，辅助边框不会保存。超出照片时会询问是否扩展画布。

### 操作步骤

1. 选择照片，从图像菜单、所选图像操作或右键菜单打开“添加水印…”。地图中可使用显示区域或图钉的照片操作；编辑面板中的“添加水印…”仅针对当前照片。
2. 输入文字或签名，点击字体名称按钮，在macOS字体面板中选择此Mac已安装的字体。勾选要显示在照片上的EXIF项目，并通过“选择图像…”添加透明背景PNG等徽标或签名图像。
3. 选择9个位置之一，或在预览中拖动水印。用滑块或25.5%等数值调整大小、边距和不透明度，选择白色/黑色文字及阴影/背景。移到照片外时会询问是否扩展画布。“应用设置”后选择格式、质量、缩小尺寸和文件夹，再开始转换。

### 拍摄信息与固定文字大小

EXIF将各原图的拍摄时间、制造商、型号、镜头、快门速度、光圈、ISO、焦距和文件名绘制为文字。缺失或无法读取的拍摄信息会省略。添加EXIF只会增加行数或换行，不会缩小文字。要修改嵌入的元数据，请使用图像信息中的元数据编辑功能。

### 拖动位置与扩展画布

文字和徽标大小基于扩展前的照片宽度，徽标保持宽高比。按短边计算的边距仅用于预设位置；拖动后使用自定义位置。相对位置、大小和扩展确认应用于整组选中照片，不缩放照片，仅添加各自必要的边缘。新增区域在透明度支持格式中透明，在JPEG中为白色。“保持在图像内”只将外侧位置移回内部。若内容本身过大，可选“扩展画布”“缩小水印以适应”或“取消”。取消保留当前设置。仅在未扩展画布且内容无法放入照片时，解决问题前不能保存。恢复原画布时也会检查内容是否过大。

### 副本、预览与记住的设置

水印在调整、裁剪、旋转和输出缩小后应用。首张照片的缩略预览因像素取整可能与最终位置略有差异；其他照片的尺寸和EXIF也可能不同。原图和分类保持不变，完成的副本可通过macOS共享。样式和自定义位置会记住，但每次新转换都需手动启用水印。每批新任务会重置扩展许可；再次拖到照片外时会重新确认。徽标源图像应留在同一路径，无法读取时会提示。不支持视频；动画和多页图像保存第一帧为静态图像。

### 实用提示

- 文字最多2,000字、20行；徽标使用ImageIO可读取图像的第一帧。大小2–90%，边距0–20%，不透明度0–100%。越界数值限制在上下限内，无效输入保留上次有效值。扩展后的最终输出限64MP、每边32,768px以内，超出时请内移或缩小水印。原图查看器不会显示水印。

默认同时显示照片和视频。“一览无余”中的视频显示静态预览，单独查看视频时初始为暂停。通过“帧与片段编辑…”提取PNG或保存片段副本，原文件保持不变。

![视频预览、逐帧和时间导航，以及片段范围与保存质量。](figures/video.png)

**界面 11.** 视频预览、逐帧和时间导航，以及片段范围与保存质量。

1. **视频播放器** — 按播放查看画面并收听声音。刚打开时保持暂停。
2. **帧与时间** — 视频支持时可移到实际相邻帧，也可通过滑块定位播放时间。
3. **片段范围与质量** — 指定起止时间、MP4或MOV格式及质量，保存新副本。

### 操作步骤

1. 多图视图中，将指针移到视频上即可静音播放，点击“开启声音”可听到声音。移开指针会停止播放并再次静音。在一览无余或查看器中双击视频，会单独以全屏打开，沿用当前时间和静音状态自动播放。用控件控制播放、跳转和声音；按Esc或“关闭全屏”返回原来的排列。“显示视频”可在列表、菜单或设置中关闭，GIF不受影响。
2. 打开视频后选择“帧与片段编辑…”。拖动播放位置滑块按时间浏览；视频支持时，可用“上一帧”“下一帧”查看实际相邻画面。“将当前帧提取为PNG…”会保存当前位置的静态画面。
3. 用“将当前位置设为起点”“将当前位置设为终点”或秒数输入框指定范围，选择MP4或MOV和保存质量，再点“保存片段副本…”。“减小文件大小预设”会选择MP4和最高720p。完成后可在访达中显示，或通过macOS原生共享发送。

### 支持的视频与限制

支持当前macOS内置功能能够解码的MP4、MOV等视频。即使扩展名相同，支持情况仍取决于内部的视频和音频编解码器，无需安装外部编解码器。不支持WebM、MKV或ZIP中的视频。受DRM等保护的视频不能保存帧或片段。

### 时间与帧边界

保存范围包含起点、不包含终点，实际边界会对齐视频采样。可变帧率视频不显示精确连续的帧编号。无法逐帧移动时，请按时间查找。PNG提取不应用片段保存的质量设置。

### 与图像功能的区别

视频不参与图像编辑、AI放大、壁纸设置或批量图像转换。当前列表包含视频时，不能开始电子相册；关闭“显示视频”并仅显示图像后即可使用。图像对比仅处理图像，地图的GPS搜索也不包含视频。视频仍可分类、重命名和共享所选原文件。新副本不会自动继承原文件的分类。

### 实用提示

- 片段保存为新的H.264视频副本；若有音频，则使用AAC。不会放大尺寸较小的视频，也不保证文件大小减少。原文件和已有输出文件不会被覆盖；取消时会删除未完成的副本。

## 13. 逐帧查看动画并保存片段

查看macOS能够解码的GIF、APNG或WebP动画帧，保存PNG静态图像或GIF、APNG片段副本。原文件与照片编辑调整保持不变。

![动画帧预览，以及片段范围、尺寸和保留帧设置。](figures/animation.png)

**界面 12.** 动画帧预览，以及片段范围、尺寸和保留帧设置。

1. **帧预览** — 检查所选帧。此处的输出不会应用照片编辑调整。
2. **帧控制** — 使用逐帧、播放或暂停和滑块导航，查看从1开始的帧编号。
3. **范围与缩小** — 选择包含起止帧的范围、输出格式、按比例缩小和保留帧的间隔。

### 操作步骤

1. 打开多帧GIF、APNG或WebP，选择“帧与片段编辑…”。使用“上一帧”“下一帧”或滑块定位，也可播放或暂停以检查动画。帧编号从1开始。
2. 选择“将当前帧提取为PNG…”可按原始像素尺寸保存当前静态画面。如需保留动画，用“起始帧”“结束帧”或当前位置按钮设置范围；起止两帧均包含在内。
3. 将片段格式设为GIF或APNG，选择图像大小及保留帧的方式，再点“保存片段副本…”。“减小文件大小预设”会设置50%尺寸并每2帧保留1帧。成功保存后，可在访达中显示，或通过共享按钮发送至macOS共享目标。

### 按比例缩小尺寸

片段副本的尺寸可选“原始大小”“长边（px）”或“比例（%）”。比例范围为1–100%，保持宽高比且不放大小图像。尺寸设置用于片段副本；当前帧的PNG提取仍使用原始像素尺寸。不会应用照片编辑中的颜色调整、旋转或裁剪。

### 帧数与播放时长

可以保留所有帧，或每2、3、4帧保留1帧。被跳过帧的显示时间会加到前一个保留帧，因此保持所选范围的总时长。保留的帧越少，动作越不连贯。末尾不足一个间隔或仅包含一帧的范围也可保存。

### 格式与文件大小限制

读取支持取决于当前macOS运行环境。WebP可作为输入，动画输出为GIF或APNG。GIF的颜色数量和透明度有限，半透明及颜色表现可能变化。缩小或减少帧数也不保证压缩文件，输出副本可能比原文件更大。

### 实用提示

- 不会覆盖原文件或已存在的同名文件。请选择其他名称或保存位置。取消时会删除未完成的副本，只有成功保存的结果才可共享。新副本不会自动继承原文件的分类。

## 14. 放大查看并比较 AI 放大结果

AI 放大会创建宽和高分别加倍的新图像。保存 PNG 副本前，可以放大检查细节，并与原图的同一区域进行比较。

![通过调整缩放比例和分界线，比较原图与 AI 放大结果中同一区域的预览。](figures/ai-upscaling.png)

**界面 13.** 通过调整缩放比例和分界线，比较原图与 AI 放大结果中同一区域的预览。

1. **视图与缩放** — 选择“AI 放大结果”或“与原图比较”，通过 +/−、缩放百分比、“适合窗口”和“100% · 实际像素”检查细节。
2. **原图与 AI 结果的分界线** — 移动左侧原图与右侧 AI 结果之间的分界线。拖动图像或滚动时，两侧会一起移动。
3. **保存 PNG 副本** — 无论预览缩放比例如何，都会将完整的 2 倍结果保存为 PNG 副本。

### 操作步骤

1. 选择照片，打开“AI 放大…”，点击“开始 AI 放大”。处理完成后，预览中会显示“AI 放大结果”。
2. 使用 +/− 按钮或触控板捏合手势缩放。拖动图像或滚动以移动到需要检查的细节；选择“适合窗口”可再次显示整张图像。
3. 选择“与原图比较”，左右拖动分界线。左侧是原图，右侧是 AI 结果，两侧使用相同的缩放比例和位置。检查后点击“保存 PNG 副本…”。

### “100% · 实际像素”的含义

100% 表示将 AI 结果的 1 个像素映射到屏幕的 1 个物理像素。此比例会考虑 Retina 缩放，因此窗口的点数尺寸不一定等于图像的像素尺寸。百分比以 AI 结果为基准，而不是原图。“适合窗口”会调整比例，使整张图像可见。这些操作只改变预览，不改变文件尺寸或保存结果，也不会重新运行 AI 处理。

### 比较同一处细节

左侧原图通过普通插值按 2 倍显示，以匹配 AI 结果的宽和高。两侧共享缩放与移动位置，拖动分界线即可比较同一处轮廓和纹理。拖动分界线改变比较范围，拖动图像其他位置则移动图像。AI 生成的细节属于推测，不能保证恢复原图中缺失的真实信息。

### AI 输出与限制

内置模型通过 Core ML 在本机运行，不上传照片，使用时也不需要下载模型。宽和高分别放大两倍。输出为 8-bit SDR sRGB PNG，透明度单独插值。动画输入使用第一帧，不包含查看器中的编辑。输出最多 6400 万像素，内存较少的 Mac 可能更低。关闭前请保存；AI 生成的细节属于推测。

### 实用提示

- 不提供 AI 4 倍放大、HDR AI 输出或批量 AI 放大。关闭前请保存 PNG 副本。原始文件不会改变。

## 15. 了解显示质量、HDR 与加载

“高画质缩放”改变显示插值方式。“AI 放大”创建可保存的更大图像。HDR 输出是一项显示偏好，并不能证明当前照片为 HDR。

### 操作步骤

1. 开启“高画质缩放”可使显示更平滑。其左右或上下对比显示同一张照片，并同步缩放与移动；按 Esc 关闭该对比。
2. 用 HDR ON / HDR OFF 允许或禁用扩展亮度显示。在“设置 → 通用 → 图像加载”中，根据工作需要选择“最优先”“流畅”“一般”或“慢速”。

### 格式与性能

读取和写入支持取决于正在运行的 macOS。应用额外提供 QOI、常见 PCX 解码和 SVG/SVGZ 后备显示方式，不包含 BPG 和 .clip。“流畅”是默认加载模式。所有模式都会根据内存压力、发热、低电量、其他应用或较慢存储而减缓处理。

### 实用提示

- 快速浏览时，在最终图像准备好之前，可能暂时显示小预览或上一张照片。

## 16. 播放电子相册或设置壁纸

“电子相册”在专注的单图视图中自动浏览当前列表。壁纸使用为所选显示器准备的独立副本。

### 操作步骤

1. 打开包含至少两张照片且没有视频的列表。若显示了视频，先关闭“显示视频”。选择“导航 → 电子相册 → 播放电子相册”，或按⌃⌥P。
2. 通过播放控件暂停。从时间控件或“设置 → 通用 → 电子相册”中设置 1–300 秒的间隔，并选择是否重复。
3. 要设置壁纸，先回到普通查看器，选择“图像 → 将当前图像设为桌面壁纸…”，或按 ⌃⌥W。选择当前显示器或全部已连接显示器、“填满屏幕”或“完整显示照片”，以及是否应用当前调整，然后应用。

### 播放方式

默认间隔为五秒，重复开启。预览或图像显示后才开始计时，所以加载时间不会占用观看间隔。手动浏览或改变间隔会重新计时。关闭重复时，播放停在最后一张。

### 自动暂停

退出专注模式、切换到其他应用、进入睡眠或开始文件操作时会暂停。仅播放期间保持屏幕唤醒。重新启动会恢复设置，但不会自动开始相册播放。

### 壁纸副本

应用创建 PNG，不更改源文件。动画使用第一帧，HDR 转为 SDR。副本不含 EXIF/GPS，按显示器尺寸生成，最大 8192 像素，并保存在应用的 Application Support/Wallpapers 文件夹中。其他桌面空间遵循 macOS 的行为。旧副本可能仍被其他空间使用，因此不会自动删除。 视频不能用于设置壁纸。

### 实用提示

- 无法播放时，请检查筛选后的列表是否至少有两张照片，且不包含视频。启用了分类、图像对比或其他操作时也不能开始播放。

- “通用”还列出这台 Mac 可用的原生格式，并提供“清除图像缓存”。如果使用其他应用时想减少后台工作，可选择较慢的加载模式。 RAW 缩略图会优先使用可用的内嵌预览；大小足够的缩略图可在切换查看模式时重复使用。首次显示速度取决于文件和 Mac 环境。

## 18. 快捷键与快速排查

后面的参考表列出默认操作键和固定的情境快捷键。⌘ 表示 Command，⌥ 表示 Option，⌃ 表示 Control，⇧ 表示 Shift。

**界面 15.** “快捷键”标签页显示可配置操作及冲突提示。

1. **操作** — 将指针停在操作名称上，了解适用位置和具体作用。
2. **按键与修饰键** — 选择按键，再切换 Control、Option、Shift 或 Command。
3. **冲突与默认值** — 解决重复组合，或使用“恢复默认设置”重新开始。

### 操作步骤

1. 打开“设置 → 快捷键”可更改操作按键与修饰键。更改会保存，当前分配也会显示在菜单中。
2. 为多个操作分配相同组合时，请检查冲突标记。将指针停在操作名、按键选择器、修饰键或冲突图标上可查看帮助。“恢复默认设置”重置可配置的操作键。

清除搜索、格式、分类和地图筛选，并检查此 macOS 是否支持输入格式。空文件夹仍可打开，以便继续浏览子文件夹。驱动器断开或集合已移动时，通过“打开…”重新选择。

### 命令不可用

先完成或取消当前文件操作。编辑、批量转换或设置壁纸前，请退出图像对比。ZIP 内的图像不能直接改名或改写原始元数据。地图结果按钮需要等待计算完成且选择结果非空。

### Space、Esc 与 Option 方向键

仅当未给单独的 Space 分配自定义操作且未在输入文字时，Space 才切换专注模式。Esc 逐步退出当前模式或取消选择手势。查看器的 Option 方向键翻页固定不变，但若将同一组合分配给自定义普通查看器操作，则自定义操作优先。

### 实用提示

- 圆形 i 和滑块形按钮分别打开照片信息与编辑。请使用按钮或“导航”菜单；在此版本中，I 和 E 不是默认的面板切换快捷键。
