# 알맹Re 앱 아이콘

2026-09-16 사용자가 선택한 「두 프레임에 삼색을 붓는 모습」을 유지하면서, 추가 요청에 따라 아이콘 바깥의 흰색 사각 배경을 투명하게 수정했습니다. 두 프레임 안쪽의 흰색과 삼색은 유지합니다.

- `AppIcon.png`: 실제 알파 채널이 있는 1254 × 1254 RGBA PNG. 아이콘 바깥과 캔버스 모서리는 투명합니다.
- `AppIcon.icns`: 원본에서 16–1024픽셀의 macOS 아이콘 크기를 만든 배포 자산
- `AppIcon-source.json`: 원래 선택한 이미지, 투명 배경 수정 결과와 파일 해시 기록
- `Info.plist`: `CFBundleIconFile`을 `AppIcon`으로 지정

아이콘 파일을 다시 만들 때:

```bash
bash scripts/make-app-icon.sh
```

`scripts/build-app.sh`는 `AppIcon.icns`를 앱의 `Contents/Resources`로 복사한 후 서명합니다. 아이콘 패키징은 투명 알파 채널을 유지하며 크기 변환만 수행합니다.

디자인 시안과 타사 참고 자료는 로컬 개발 기록으로만 보관합니다. 저장소에는 빌드에 사용하는 확정 PNG와 ICNS를 포함합니다.

최종 편집 지시: 두 프레임과 삼색 붓기 모티프를 유지하고, 바깥 사각 배경만 투명하게 처리했습니다. 프레임 내부의 흰 영역은 불투명하게 유지했습니다.
