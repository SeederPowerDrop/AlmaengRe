# 알맹Re

빠르고 단정한 macOS용 무료 오픈 소스 이미지 뷰어입니다. 반디뷰의 이미지 중심 흐름에서 영감을 받되, SwiftUI·트랙패드·Apple 컬러 파이프라인에 맞게 새로 설계합니다.

이 브랜치는 **0.11 개발 버전**입니다. 기존 **0.10.2**는 `main`과 `v0.10.2` 태그에 보관하고, 새 기능과 Rust 엔진 전환은 `codex/rust-engine-library-upgrade`에서 진행합니다. 폴더 탐색·이미지 비교·편집·변환에 파일명 자동 비교, 검색·정렬, 즐겨찾기·보기 복원, ZIP 열기, AI 2배 확대를 더합니다. 초대형 이미지 타일 렌더링과 Developer ID 배포 서명·공증은 별도 과제입니다.

## 프로젝트의 출발점

이 프로젝트에는 2000년대 국산 이미지 뷰어 **알맹이3**에서 느꼈던 개인적인 추억이 담겨 있습니다. 많은 이미지를 한눈에 훑고, 작은 아이콘을 크게 펼쳐 보고, 확대해도 부드럽게 보이던 경험을 오늘의 macOS에서 이어가고자 합니다.

**알맹Re**는 그 경험을 다시 이어가고 싶다는 마음으로 붙인 이름입니다. ‘Re’에는 다시 보고, 다시 만든다는 의미를 담았습니다. 언젠가 원 개발자에게도 이 작은 인사가 닿기를 바랍니다.

알맹이3에 대한 오마주이며 공식 후속작은 아닙니다. 원작의 코드나 자산을 사용하지 않는 독립 오픈 소스 구현으로 개발합니다.

## 이미지 편집

사진을 선택하고 상단 **이미지 편집**(슬라이더 아이콘)을 눌러 편집 패널을 엽니다. 몽땅보기에서 열면 선택한 사진이 있는 뷰어로 전환합니다.

- **구도:** 잘라내기에서 사진 위를 드래그해 영역을 만들고, 안쪽 드래그로 이동하거나 모서리로 크기를 조절합니다. 비율 선택·영역 수치 입력·전체 선택을 지원하며, 적용 전 취소하면 기존 편집이 유지됩니다. 좌우 회전은 90도 단위입니다.
- **빛:** 노출(−4~+4 EV), 휘도, 대비, 하이라이트를 조정합니다.
- **색상:** 색조, 상대 색온도(차갑게/따뜻하게), 색선명도(Vibrance), 채도, 색상 반전을 조정합니다.
- **디테일:** 선명도와 노이즈 감소를 조정합니다. 디테일 효과는 실제 크기 보기와 최종 저장 파일에서 확인하세요.

**초기화**는 현재 사진의 모든 조정을 되돌리고, **자르기 해제**는 다른 보정을 유지하며 잘라내기만 해제합니다. 편집값은 현재 실행 중 사진별로 유지됩니다. 앱을 종료하기 전에 **내보내기…**로 결과를 저장하세요. 기본 파일명은 `원본이름-edited`이며, 원본과 같은 파일에 저장하는 것은 차단합니다.

## AI 확대

사진을 선택한 뒤 상단 **AI 확대** 또는 **이미지 → AI 확대…**를 엽니다. **AI 확대 실행**을 누르면 QuickSRNet Small 2× 학습 모델로 가로·세로를 각각 2배 확대합니다. 진행률과 취소를 지원하며 **원본과 비교**, **실제 픽셀**로 결과를 확인한 뒤 **PNG 사본 저장…**으로 저장합니다.

- 모델은 앱에 포함되어 있고 Core ML이 이 Mac에서 실행합니다. 사진 업로드, 계정, 실행 중 모델 다운로드는 필요하지 않습니다.
- 현재 결과는 **8-bit SDR · sRGB**이며 투명도는 별도로 보간해 유지합니다. 애니메이션은 첫 프레임을 사용하고, 보기에서 적용한 편집값은 AI 입력에 합성하지 않습니다.
- 출력은 최대 6,400만 픽셀이며 메모리가 적은 Mac에서는 더 낮은 상한을 사용합니다. 원본 덮어쓰기는 차단합니다.
- 모델이 추정한 세부 표현은 실제 피사체와 다를 수 있습니다. 현재 범위는 2배 확대이며 HDR 출력, 4배 확대, 일괄 AI 처리는 포함하지 않습니다.

보기용 **고화질 확대**는 화면 보간 설정입니다. AI 확대는 사용자가 실행하고 사본을 저장하는 별도 작업입니다. 모델은 Qualcomm의 BSD-3-Clause 라이선스를 따르며, 출처·체크섬·변환 재현 방법은 [모델 문서](Sources/ImageViewer/Resources/AIModels/README.md)에 있습니다. Intel용 빌드 경로는 제공하지만 실제 Intel 하드웨어 추론은 검증하지 않았습니다.

## 포맷 지원 전략

지원 포맷은 실행 중인 macOS의 `CGImageSourceCopyTypeIdentifiers()` 결과를 동적으로 사용합니다. macOS 15 기준으로 JPEG/JPEG 2000, PNG/APNG, GIF, TIFF, BMP, HEIC/HEIF, AVIF, JPEG XL, WebP, PSD, TGA, DDS, OpenEXR, Radiance HDR, ICO/ICNS, KTX/KTX2, ASTC/PVR 및 폭넓은 카메라 RAW를 네이티브로 읽습니다.

Image I/O 밖의 QOI와 PCX는 자체 디코더로 보완하고, SVG/SVGZ는 AppKit 표현 폴백을 사용합니다. BPG와 Clip Studio `.clip`은 아직 포함되지 않았습니다. 자세한 범위와 원칙은 [포맷 문서](docs/FORMAT_SUPPORT.md)를 참고하세요.

## 실행

요구 환경은 **macOS 14 이상, Xcode 16 이상, Swift 6, Rust 1.94 이상**입니다. Rust 의존성은 `Cargo.lock`으로 고정합니다. 새로 내려받은 저장소에서는 Swift 실행·테스트·Xcode 실행에 앞서 Rust 정적 라이브러리를 만들어야 합니다.

```bash
./scripts/build-rust-engine.sh native
swift run
```

이후 Finder에서 `Package.swift`를 Xcode로 열고 `ImageViewer` 실행 대상을 선택할 수도 있습니다. Rust 엔진을 수정했다면 Swift를 다시 실행하기 전에 위 Rust 빌드를 반복하세요. 기본 앱 빌드 스크립트는 이 단계를 자동으로 수행합니다.

일반 `.app` 번들을 만들려면 다음을 실행합니다.

```bash
rustup target add aarch64-apple-darwin x86_64-apple-darwin
./scripts/build-app.sh release universal
open "dist/알맹Re.app"
```

기본 결과는 Apple Silicon과 Intel을 함께 지원하는 Universal 2 앱이며, 릴리스 빌드는 같은 버전의 GitHub 배포용 ZIP도 생성합니다. 빠른 로컬 빌드만 필요하면 `./scripts/build-app.sh debug native`를 사용하세요. 스크립트 결과는 로컬 실행용 ad-hoc 서명이며, GitHub Release로 배포할 때는 Apple Developer ID 서명과 공증이 별도로 필요합니다.

포함된 AI 모델은 일반 앱 빌드에 Python이나 재변환이 필요하지 않습니다. 모델을 재현·변경할 때만 [별도 변환 환경](Sources/ImageViewer/Resources/AIModels/README.md#reproduction)을 사용합니다.

## Rust 엔진과 네이티브 경계

Rust 엔진은 폴더 열거, 파일명 매칭, 검색·필터·정렬, ZIP 검증·해제, QOI/PCX 파싱, 디코딩 동시성·캐시·픽셀 예산과 CPU·발열·메모리 상태에 따른 적응 정책을 담당합니다. C ABI로 정적으로 연결하며 별도 Rust 런타임 설치는 필요하지 않습니다.

SwiftUI/AppKit은 UI·접근성·권한·북마크를, ImageIO는 macOS 포맷·RAW·메타데이터를, CoreImage/CoreGraphics는 색 관리·HDR·화면 이미지를, Core ML은 AI 추론을 담당합니다. Swift actor의 취소·작업 스케줄링과 네이티브 이미지 캐시 수명 관리도 유지합니다. 모든 앱 코드와 Apple 프레임워크를 Rust로 대체한 구조는 아닙니다.

Rust 전환만으로 성능 향상이나 메모리 누수 부재를 보장하지 않습니다. 경계에서 버퍼 소유권을 명시하고, 크기 상한·취소·회귀 검증을 함께 유지합니다. 구체적인 범위와 빌드는 [엔진 문서](Engine/README.md), 의존성 라이선스는 [Rust 라이선스 모음](Engine/THIRD_PARTY_NOTICES.txt)에 있습니다.

| 확대 품질 비교 종료 | `⌃⌥0` 또는 `Esc` |

`⌃`는 Control, `⌥`는 Option입니다. 이동 단축키는 마우스를 움직이는 대신 **이동 방식을 선택**합니다. 위 동작 키는 **알맹Re → 설정 → 단축키**에서 변경할 수 있습니다(`Esc` 돌아가기는 고정). 메뉴에도 현재 지정된 단축키를 표시합니다.

썸네일 패널 위치와 확대 이미지 이동 방식은 툴바/하단 조작부에서 바로 바꾸거나 **알맹Re → 설정 → 일반**에서 지정할 수 있습니다. 하단 **고화질 확대** 메뉴, **확대/축소 → 고화질 확대 및 비교**, 일반 설정에서 고화질 확대를 켜고 끄거나 **좌우 비교 / 상하 비교**를 선택하세요. 두 칸은 같은 이미지·애니메이션 프레임을 공유하며 확대 배율과 이동 위치가 함께 바뀝니다. **실제 크기(1) → 확대(=)** 순서로 작은 이미지를 확대하면 픽셀 경계 차이가 잘 보입니다. 고화질 확대를 끄면 비교도 종료되며, 비교 중 `Esc`는 비교만 먼저 닫습니다.

고화질 확대 선택과 몽땅보기 썸네일 크기는 다음 실행에도 유지됩니다. 같은 이미지의 확대 품질 비교는 재실행 시 끄기로 시작합니다. 몽땅보기 범위는 기존 최소/최대에서 각각 30% 확장한 **44.8~665.6pt**이며 좁은 창에서는 실제 셀만 가용 너비에 맞춥니다. 몽땅보기는 뷰어의 고화질 확대 설정과 별개로 항상 고품질 보간을 적용하고, 큰 썸네일은 빠른 미리보기 뒤 원본 기반 결과로 보강합니다. 이는 거친 계단 현상을 줄이는 표시 보간이며, 원본에 없는 세부 정보를 복원하는 AI 초해상도는 아닙니다. 보기용 고화질 확대/비교 설정은 원본이나 내보내기 파일을 변경하지 않습니다.

0.4.5의 **고화질 확대**는 기존 AA 기능의 새 표시 이름입니다. 현재 확대는 선형 보간, 축소는 삼선형 필터를 사용합니다. 이미지 편집 패널의 **선명도**는 보기용 보간과 별도로 저장 결과에도 반영되는 보정입니다.

같은 설정 화면의 **이미지 로딩**에서 최우선·쾌적·일반·느림을 고를 수 있으며 선택은 저장됩니다. 기본 **쾌적**은 16GB 이상·8코어 Apple Silicon에서 이미지·썸네일·정보 읽기를 합쳐 최대 2개씩 처리합니다. 모든 모드가 다른 앱 사용, 높은 CPU 부하, 메모리 압박, 발열과 저전력 모드에 따라 자동으로 감속합니다. 외장 SSD는 최대 2개, SD카드·네트워크·분류 불명 장치는 1개씩 읽으며 이웃 사진 선읽기도 줄이거나 멈춥니다.

16GB Mac의 기본 출력 이미지 캐시는 정밀 128MiB와 썸네일 64MiB입니다. 화면 이미지와 코덱 임시 공간 등을 포함한 앱 전체 메모리의 상한은 아니며, 압박이 생기면 캐시 예산도 줄입니다. 일반 폴더는 내부 SSD로 복제하거나 별도 영구 이미지 캐시를 만들지 않습니다. ZIP은 열어 둔 동안 전용 임시 폴더에 이미지 항목을 해제하며, 목록의 마지막 참조가 해제되면 정리합니다. 상세 계산과 실제 검증 범위는 [로딩 설계 문서](docs/IMAGE_LOADING.md)를 참고하세요.

## 몽땅보기 번호와 선택

몽땅보기 하단의 `#` 버튼 또는 **설정 → 일반 → 몽땅보기 → 몽땅보기 번호 표시**에서 번호를 켜고 끌 수 있습니다. **탐색** 메뉴에도 같은 항목이 있습니다. 번호 표시 설정은 몽땅보기에만 적용되며 사이드바 번호는 유지됩니다.

번호 배지의 실제 크기를 디코딩된 썸네일의 aspect-fit 표시 면적과 비교합니다. 면적의 ¼ 이상을 덮거나 사진 안에 여백과 함께 들어가지 않으면 사진 밖 카드 왼쪽 위로 이동합니다. 별도 이미지 크기 조회나 추가 디코딩은 하지 않습니다.

이미지나 빈 공간에서 마우스 왼쪽 버튼으로 드래그하면 사각형에 걸치는 카드들을 선택합니다. 드래그 시작 시 누른 `Shift`는 기존 선택에 추가하고, `⌘`는 영역 안 선택을 반전합니다. `Esc`는 드래그 전 선택으로 되돌립니다. 드래그 중에는 활성 이미지·메타데이터·보기 위치를 바꾸지 않고 선택만 갱신합니다. 일반 클릭, ⌘/⇧ 클릭, 더블클릭으로 단일 보기 전환은 그대로 사용할 수 있습니다.

## 이미지·폴더·ZIP 열기

시작 화면·상단 왼쪽·파일 메뉴의 **열기…** 또는 `⌘O`는 모두 같은 선택 창을 엽니다. 폴더와 이미지 버튼을 따로 고를 필요가 없습니다.

- 폴더를 선택하면 그 폴더의 사진 목록을 엽니다.
- ZIP을 선택하면 압축 안의 지원 이미지 목록을 엽니다.
- 이미지 한 장을 선택하면 그 사진을 바로 표시하고, 같은 폴더의 다른 사진도 이어서 볼 수 있습니다.
- 이미지 여러 장은 선택한 사진만 엽니다. 폴더와 이미지를 함께 고르면 선택한 폴더의 사진과 개별 이미지를 중복 없이 모읍니다. 하위 폴더까지 자동으로 포함하지는 않습니다.
- 이미지 비교 중에는 선택한 A/B 칸에 엽니다. 각 칸의 **열기…**도 같은 방식이며 잠긴 칸은 바뀌지 않습니다.

기본 실행 파일은 `dist/알맹Re.app`입니다. 버전별 보관본과 함께 이 경로도 최신 버전으로 갱신합니다. 창 제목에서 실행 중인 버전을 확인할 수 있습니다. 옛 화면이 보이면 실행 중인 앱을 ⌘Q로 종료하고 Finder에서 기본 앱을 선택한 뒤 ⌘O로 여세요.

### ZIP의 지원 범위

ZIP의 Stored/Deflate 압축과 ZIP64 메타데이터를 읽습니다. 암호화 또는 다른 압축 방식은 오류로 알립니다. 하위 경로의 이미지도 목록에 포함하고, ZIP 내부 경로와 원본 ZIP 위치로 마지막 보기 대상을 구분합니다.

압축 파일은 최대 **2 GiB**, 디렉터리 메타데이터는 **16 MiB**, 항목은 **1만 개**, 해제 크기는 항목당 **256 MiB·전체 1 GiB**로 제한합니다. 압축률 제한과 경로 탈출·심볼릭 링크·중복 경로 검사를 적용합니다. 이미지는 열 때 전용 임시 폴더에 해제하며, 항목을 볼 때마다 해제하는 방식은 아닙니다.

ZIP 안의 이미지는 **읽기 전용**입니다. 이름 변경이나 메타데이터 원본 수정을 하려면 먼저 새 파일로 내보내세요. ZIP 자체를 다시 쓰거나 안의 파일을 교체하는 기능은 포함하지 않습니다.

## 검색과 정렬

상단 **파일 이름 검색**에서 현재 목록의 파일명을 찾습니다. 대소문자를 구분하지 않고, 공백으로 나눈 검색어가 모두 들어간 항목을 보여 줍니다. 이미지 내용·사물·OCR 검색은 포함하지 않습니다. **형식** 메뉴는 JPEG·PNG·HEIC·RAW·GIF·WebP·TIFF·기타를 여러 개 선택할 수 있으며, **모든 형식**으로 필터를 해제합니다. 검색·필터는 원본 목록을 변경하지 않습니다.

**정렬**은 이름 오름차순/내림차순, 수정일·생성일 최신순/오래된순, 용량 큰순/작은순, GPS 북→남/남→북/동→서/서→동을 제공합니다. 이름은 숫자를 자연스럽게 비교하므로 `2`가 `10`보다 먼저 나옵니다. GPS 정렬에서 위도는 남북, 경도는 동서를 판단하며 위치가 없는 사진은 어느 방향에서도 뒤로 보냅니다. GPS는 해당 정렬을 고를 때 픽셀 디코딩 없이 메타데이터로 읽습니다.

이미지 비교 화면에서도 같은 검색·형식·정렬 조건을 두 목록에 적용할 수 있습니다. **같은 파일명** 모드의 대응 행도 선택한 정렬을 따르며, 날짜·용량·GPS는 A 이미지의 값을 우선 사용하고 A가 없는 행은 B의 값을 사용합니다.

## 폴더 트리

상단 **폴더 트리** 버튼을 누르면 왼쪽에 폴더를 펼쳐 탐색하는 패널이 나타납니다. **열기…**는 이미지나 폴더를 빠르게 선택할 때 사용합니다. 트리의 표시 여부는 다음 실행에도 유지되며 **탐색 → 폴더 트리 표시**와 설정에서도 바꿀 수 있습니다.

- 폴더 왼쪽 화살표는 하위 폴더를 펼치거나 접습니다. 폴더 이름은 해당 폴더의 사진을 엽니다. 다른 폴더로 옮겨도 이미 펼친 분기는 유지됩니다.
- 처음에는 현재 사진 폴더와 같은 위치의 다른 폴더가 보입니다. 아직 사진을 열지 않았다면 사용자 홈 폴더에서 시작합니다.
- 트리 위의 폴더 버튼은 탐색 시작 위치를 고릅니다. 위쪽 화살표는 한 단계 상위 폴더를 보여 주고, 새로고침은 파일 시스템의 변경을 반영합니다.
- 썸네일이 왼쪽에 있으면 트리 아래에 함께 표시됩니다. 두 영역 사이의 구분선을 드래그해 높이를 조절할 수 있습니다.
- 몽땅보기에서 폴더를 바꾸면 몽땅보기를 유지합니다. 이미지가 없는 폴더도 열어 두고 그 하위 폴더로 계속 이동할 수 있습니다.
- 이미지 비교에서는 트리 위의 **A / B**로 폴더를 바꿀 칸을 선택합니다. 잠긴 칸은 변경하지 않습니다.

폴더 트리 위의 핀 버튼이나 폴더 행의 우클릭 메뉴에서 **즐겨찾는 폴더에 고정**을 선택하면 트리 위에 고정합니다. 고정된 폴더를 눌러 바로 열 수 있고, 해제 버튼으로 목록에서 뺄 수 있습니다. 즐겨찾기는 재실행 후에도 유지됩니다.

트리는 펼치는 단계만 읽으며 폴더 전체를 재귀 스캔하지 않습니다. 숨김 폴더, 앱 같은 패키지, 심볼릭 링크는 목록에서 제외합니다. 접근할 수 없는 폴더는 트리에 오류 표시를 남기며, 다시 읽으려면 새로고침을 누르세요.

## 이미지 비교

툴바의 **썸네일**은 현재 폴더의 사진 목록을 표시할 위치를 고르는 메뉴입니다. **HDR ON / HDR OFF**는 HDR 출력을 허용하거나 끄는 설정이며, 현재 사진이 HDR인지 판별하는 표시는 아닙니다.

시작 화면의 **이미지 비교 시작**, 상단 **이미지 비교** 또는 `⌃⌥C`로 들어갑니다. **이미지 비교 → 비교할 폴더 선택…** 메뉴에서 바로 시작할 수도 있습니다. **비교할 폴더 선택…**을 누르면 A 폴더(1/2), B 폴더(2/2)를 차례로 고릅니다. 각 창에서 원하는 폴더 안으로 이동한 뒤 **이 폴더 선택**을 누르면 됩니다. 서로 다른 위치의 폴더도 선택할 수 있고, 중간에 취소하면 기존 비교가 유지됩니다. 비교 화면의 A/B **열기…** 버튼으로 한쪽만 바꿀 수도 있습니다. A는 왼쪽/위, B는 오른쪽/아래이며, 상단에서 좌우·상하 배치를 바꿉니다.

기본 **같은 파일명** 모드는 확장자를 뺀 이름으로 짝을 맞춥니다. 예를 들어 A의 `001.jpg`와 B의 `001.png`가 한 쌍입니다. 대소문자와 Unicode 조합 표현 차이는 정규화하며, 어느 한쪽에만 있는 이름도 비교 행에서 빠지지 않습니다. 없는 쪽에는 **대응 이미지 없음**을 표시하므로 중간에 파일이 없어도 이후 순서가 어긋나지 않습니다. 한쪽에 같은 이름의 여러 확장자가 있으면 각 항목을 하나씩 대응시키고 남은 항목은 누락으로 표시합니다.

이 모드에서 공통 이동·각 칸의 탐색·썸네일 선택은 대응 행을 기준으로 움직입니다. 한쪽을 잠그면 그 칸은 현재 사진을 유지하고 다른 칸만 바뀝니다.

기존 방식은 **목록 순서**로 선택합니다. `←`/`→`와 공통 이동 버튼이 이미지가 많은 쪽의 끝까지 넘기며, **적은 쪽 이미지**에서 **마지막 이미지 유지** 또는 **처음부터 반복**을 고릅니다. 5장과 9장이라면 유지 모드에서 `5/5 · 5/9` 다음은 `5/5 · 6/9`, 반복 모드에서는 `1/5 · 6/9`입니다. 목록 순서 모드의 각 칸 스와이프·단축키·번호 이동은 해당 칸을 개별 탐색합니다.

각 칸 하단에는 해당 폴더의 **썸네일**과 현재 위치가 표시됩니다. 썸네일을 누르면 같은 파일명 모드에서는 해당 대응 행으로, 목록 순서 모드에서는 해당 칸의 사진으로 이동합니다. 잠긴 칸은 목록 확인과 스크롤만 가능합니다. **썸네일 표시**로 사진 영역을 넓힐 수 있고, 상하 배치에서는 더 작은 썸네일을 사용합니다.

**확대·이동 함께**를 켜면 두 사진의 같은 상대 위치를 중심으로 핀치·확대·이동이 함께 적용되고, 끄면 각각 조작합니다. 비교 화면에서는 일반 뷰어의 이동 설정과 관계없이 확대 중 트랙패드 두 손가락 이동을 사용할 수 있습니다.

각 칸의 **잠금**을 누르면 그 칸의 사진·배율·이동 위치가 고정됩니다. 다른 칸만 확대하거나 움직이고 다음 사진으로 넘길 수 있으며, `←`/`→`도 잠기지 않은 칸만 넘깁니다. **잠김**을 다시 누르면 잠금이 풀립니다. 배치·연동·적은 쪽 처리·썸네일 표시 설정은 다음 실행에도 유지됩니다. `Esc` 또는 비교 종료 버튼은 비교 전 뷰어/몽땅보기로 돌아가며 기존 폴더와 선택 위치를 보존합니다. 마지막 비교 입력과 위치·배율·이동·잠금도 다음 실행을 위해 저장합니다.

이 모드는 원본을 확인하는 읽기 전용 비교입니다. 일반 뷰어에서 적용한 보정값은 가져오지 않으며, 잘못된 파일을 수정하지 않도록 편집·일괄 작업·바탕화면 설정은 비교 밖에서 사용합니다. 두 칸이 기존 디코더와 캐시를 공유하므로 별도의 이미지 엔진은 추가하지 않습니다.

## 마지막 보기 복원

앱을 다시 실행하면 마지막으로 연 입력, 선택한 사진, 뷰어/몽땅보기/이미지 비교 상태, 배율·이동, 검색·필터·정렬 조건을 복원합니다. 이미지 비교는 A/B 입력과 각각의 사진·잠금, 비교 방식과 대응 행 위치를 저장합니다. 일반 파일은 파일 위치로, ZIP 이미지는 원본 ZIP과 내부 경로로 식별해 임시 파일 경로를 저장하지 않습니다.

사용자가 허용한 폴더·파일 접근은 macOS 북마크와 함께 저장합니다. 파일이 삭제되거나 이동 후 북마크를 해석할 수 없거나 접근 권한이 달라졌다면 복원하지 못할 수 있으므로 **열기…**로 다시 선택하세요. 이미지 편집값과 AI 결과는 마지막 보기 복원에 포함하지 않으므로 종료 전 사본으로 저장해야 합니다.

## 전자 앨범과 바탕화면

이미지가 두 장 이상인 목록에서 **탐색 → 전자 앨범 → 전자 앨범 재생** 또는 `⌃⌥P`를 누르면 현재 사진부터 한 장 집중 보기로 자동 재생합니다. 하단 재생 버튼으로 일시정지하고, 시간 버튼 또는 **설정 → 일반 → 전자 앨범**에서 **1~300초**와 반복 여부를 설정합니다. 기본값은 5초·반복 켜짐입니다. 설정만 저장하며 앱을 다시 실행해도 자동 재생하지 않습니다.

사진의 미리보기나 정밀 이미지가 실제 표시된 뒤 시간을 세므로 느린 로딩 때문에 사진을 바로 건너뛰지 않습니다. 수동으로 넘기거나 간격을 바꾸면 시간을 다시 셉니다. 반복을 끄면 마지막 사진에서 멈춥니다. 집중 보기 종료, 다른 앱 전환, 잠자기 또는 파일 작업을 시작하면 일시정지합니다. 재생 중에만 화면의 자동 잠자기를 방지하며 사용자의 직접 잠자기·잠금은 막지 않습니다.

일반 뷰어에서 **이미지 → 현재 이미지를 바탕화면으로 설정…** 또는 `⌃⌥W`를 누릅니다. 적용할 화면(현재/모든 연결 화면), 사진 배치(채우기/맞춤), 현재 보정 적용 여부를 확인한 뒤 **바탕화면에 적용**을 누르세요. macOS의 다른 데스크탑 공간(Spaces) 적용 범위는 시스템 설정을 따릅니다.

바탕화면은 원본을 변경하지 않는 별도 PNG 사본입니다. RAW 등 현재 앱이 읽을 수 있는 이미지도 같은 디코더를 사용하며, 애니메이션은 첫 프레임, HDR은 SDR로 준비합니다. 화면 해상도에 맞춰 최대 8192px로 제한하고 EXIF/GPS는 복사하지 않습니다. 사본은 `~/Library/Application Support/org.openimageviewer.ImageViewer/Wallpapers/`에 보관하므로 원본을 옮기거나 외장 드라이브를 분리해도 유지됩니다. 이전 바탕화면 사본은 다른 Spaces에서 사용 중일 수 있어 자동 삭제하지 않습니다.

## 이전 버전에서 업데이트

기존 ‘이미지뷰어’ 또는 ‘알맹이Re’를 종료한 뒤 `알맹Re.app`을 실행하세요. 기존 단축키, 보기·썸네일 크기·로딩 설정의 저장 위치와 키를 유지하므로 초기화할 필요가 없습니다. 새 이름의 앱과 이전 앱을 함께 두면 Finder가 이전 사본을 열 수 있으니, 안정적인 설치 위치에 새 앱을 두고 필요한 경우 **설정 → 파일 연결**에서 원하는 형식을 다시 적용하세요. 업데이트는 사용자의 파일 연결을 자동으로 변경하지 않습니다.

## 여러 사진의 이름과 형식 바꾸기

### 몽땅보기

기존 ‘전체 보기’의 이름을 알맹이3의 기능명에서 가져온 **몽땅보기**로 바꿨습니다. 폴더의 이미지를 한꺼번에 펼쳐 보고 크기를 자유롭게 조절하는 화면입니다. 상단 모드 선택이나 `G` 키로 전환하며, 기존 사용자 지정 단축키와 썸네일 크기는 유지됩니다.

다른 언어는 발음을 옮기기보다 ‘한꺼번에 펼쳐 본다’는 뜻을 살립니다.

| 언어 | 화면 이름 |
|---|---|
| 한국어 | 몽땅보기 |
| 영어 | All at Once |
| 중국어(간체) | 一览无余 |
| 일본어 | まとめて見る |
| 프랑스어 | Tout voir |
| 스페인어 | Todo a la vista |
| 아랍어 | عرض الكل |
| 베트남어 | Xem tất cả |

### 선택과 일괄 작업

몽땅보기 또는 썸네일에서 **⌘ 클릭**으로 사진을 추가·해제하고 **⇧ 클릭**으로 범위를 선택합니다. **⌘A** 또는 선택 메뉴의 **모두 선택**으로 전체 파일을 선택할 수 있습니다. 선택한 사진 작업 메뉴, 우클릭 메뉴 또는 **이미지 → 이름 일괄 변경… / 형식 일괄 변환…**을 사용하세요.

이름 변경은 현재 이름 유지, 새 이름, 문구 찾아 바꾸기에 앞·뒤 문구와 일련번호를 조합합니다. 번호는 현재 목록 순서대로 확장자 앞에 붙으며 시작 번호·증가 간격·0 채움 자릿수·구분자를 설정합니다. 예: `IMG_1234.jpg` → `여행_IMG_1234_보정_001.jpg`. 전체 변경 미리보기에서 중복·잘못된 이름을 확인하며 문제가 있으면 적용할 수 없습니다. 적용 시 원본 파일의 이름이 바뀝니다.

확장자 이름 변경은 대소문자 정리와 `.jpg` ↔ `.jpeg`, `.tif` ↔ `.tiff` 같은 같은 형식의 표기 변경을 지원합니다. HEIC → JPEG처럼 실제 형식이 달라지면 **형식 일괄 변환**에서 저장 형식과 폴더를 고릅니다. 현재 보정값을 적용한 새 파일을 만들며 원본을 보존하고, 겹치는 이름에는 번호를 붙입니다. 애니메이션·다중 페이지 이미지는 첫 프레임만 저장합니다. 중지해도 이미 완료된 파일은 남고 저장·실패·미처리 개수를 표시합니다.

## 언어와 기본 이미지 앱

앱은 macOS가 알맹Re에 지정한 언어를 따르며 한국어, 영어, 중국어(간체), 일본어, 프랑스어, 스페인어, 아랍어, 베트남어를 제공합니다. 앱별 언어는 macOS의 **시스템 설정 → 일반 → 언어 및 지역 → 응용 프로그램**에서 바꿀 수 있습니다.

알맹Re를 먼저 `응용 프로그램` 폴더처럼 이동하지 않을 위치에 설치한 뒤 **알맹Re → 설정 → 파일 연결**을 여세요. JPEG, PNG/APNG, GIF, HEIC/HEIF, WebP, AVIF, JPEG XL, RAW 등 원하는 형식군만 선택하고 **선택한 형식에 적용**을 누르면 됩니다. 선택하지 않은 형식은 그대로 두며, macOS가 변경 확인을 요청할 수 있습니다.
